# Submission guide

Submit `retail-sales-analysis-submission.zip` if a project archive is accepted. It contains this folder with the completed notebook, HTML copies, report, SQL, results tables, chart images, audit, requirements, and setup instructions.

If only one readable report is requested, use `REPORT.html`. If code and results are requested together, use `notebooks/retail_analysis.ipynb` or `retail_analysis.html`.

The raw source workbook is deliberately omitted. The README links to UCI and explains how to reproduce all analysis outputs. The local source workbook remains in `data/raw/` on this computer.
